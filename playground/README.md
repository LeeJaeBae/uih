# UIH Playground

온라인 UIH 에디터 - 하나의 UIH 코드를 React, Vue, Svelte로 실시간 변환

## 기능

- 실시간 코드 컴파일 (React, Vue, Svelte)
- Monaco Editor 통합
- 8개 예제 갤러리
- 다크/라이트 모드 지원
- 반응형 UI

## 기술 스택

- Next.js 15.1.8 (App Router)
- React 19
- TypeScript
- Monaco Editor
- Tailwind CSS
- UIH Parser & Codegen

## 개발

```bash
pnpm install
pnpm dev
```

http://localhost:3000에서 확인

## 빌드

```bash
pnpm build
pnpm start
```

## 배포

Vercel에 자동 배포:

```bash
vercel
```
